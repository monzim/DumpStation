Everything a backup needs. Nothing it doesn't.

Any S3 bucket

AWS S3, Cloudflare R2, MinIO, Backblaze B2 and other S3-compatible storage.

Verified artifacts

SHA-256 while dumping, size checked in the bucket, re-checked before every restore.

Safe retention

Keep the last N or the last N days. The newest good backup always survives.

Schedules with time zones

Cron or presets per database. Missed runs are detected and reported.

Alerts that explain

Discord and Telegram, with typed error codes and a fix for each.

Secure by default

Encrypted secrets, passwordless sign-in with 2FA, roles and an audit log.

Agents

Back up databases your server can't reach.

Run one small container next to the database. It dials out over HTTPS, so there are no inbound ports and no VPN, and the password never leaves that host.

  • Outbound HTTPS only
  • Uploads straight to your bucket
  • Restores off unless you enable them

Running in five minutes.

Enter your domain and the commands fill themselves in. Secrets are generated in your browser.

Questions

Is it free?

Yes. MIT licensed and fully self-hosted. You pay only for your server and your storage.

What does a backup contain?

A pg_dump custom-format archive of one database. It restores with plain pg_restore, with or without DumpStation.

Which PostgreSQL versions work?

12 through 18. Every client version is bundled and the right one is picked for each server.

Where do database passwords live?

Direct databases: encrypted in DumpStation's own database. Agent databases: only on the agent host.

Can I upgrade from v1?

Yes. Pull the v2 image and recreate the container; migrations run on start. See the upgrade guide.
